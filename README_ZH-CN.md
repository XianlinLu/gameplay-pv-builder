# 游戏玩法实机演示构建器

[English](README.md) | [简体中文](README_ZH-CN.md)

Gameplay PV Builder 是一个可复用的 Skill，用来根据游戏设定、已有素材或参考视频，制作连贯的游戏宣传片、概念玩法演示和开放世界 gameplay 短片。

它会先把参考视频拆成带时间码的玩法结构，在运动生成前锁定角色和 UI 一致性，再按镜头生成可追溯的短片段，最后合成 30–60 秒成片和同步音频分层。

## 输出内容

- 角色四视图与 3D 形象卡；
- 游戏 UI 主版与场景关键帧；
- 制作简报与镜头清单；
- 逐镜头玩法视频；
- 音乐、环境、战斗、UI 和可选人声音频分层；
- 默认 45 秒，或用户指定的 30–60 秒完整成片；
- 交付与质量检查报告。

## 两种玩法结构

- **三段式实机演示：** 引导、剧情/移动、战斗/高潮。
- **开放世界都市玩法：** 城市建立、移动、探索、系统交互、冲突升级与玩法回报。

## 使用方式

提供游戏概念、已有素材或参考视频，然后调用：

```text
使用 $gameplay-pv-builder，根据这个参考视频制作 45 秒、16:9 的游戏玩法 PV。保持 HUD 像素级稳定，展示角色选择、移动探索、街巷战斗、Boss 战和结算界面。
```

Skill 会先建立连续性资料包和镜头清单，然后生成或协调短镜头；只要条件允许，就把审核通过的 UI 主版作为独立图层合成，避免 UI 在生成视频中漂移和变形。

## Lumina 导入

本仓库特意保持为纯文本结构，可以直接导入 Lumina 画布。所有被 Git 跟踪的文件都使用 Lumina 支持的小写扩展名：`.md`、`.json`、`.yaml`、`.yml` 或 `.txt`。

为避免出现 “Some documents need to be processed” 报错：

1. 按仓库原样导入，或一次性选择全部被跟踪文件。
2. 不要向导入集合添加无扩展名的 `LICENSE`；本仓库使用 `LICENSE.md`。
3. 不要把视频、图片、音频、压缩包、源代码或隐藏配置文件放进 Skill 包。
4. 生成的媒体文件保存在 Skill 包之外，只在文本清单中使用稳定 ID 或 URL 引用。
5. 文件名控制在 64 个字符以内，扩展名前只使用英文字母、数字、下划线和连字符，扩展名保持小写。

导入前请查看 [LUMINA_IMPORT.md](LUMINA_IMPORT.md) 的检查清单。

## 仓库结构

- `SKILL.md` — Skill 入口与完整工作流。
- `agents/openai.yaml` — Skill 的界面信息。
- `references` — 参考视频分析、一致性/UI 规则和音频/交付规则。
- `templates` — 可编辑的项目简报与镜头清单。
